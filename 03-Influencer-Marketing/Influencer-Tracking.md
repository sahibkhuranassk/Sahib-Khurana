# Influencer Tracking & Performance Framework

## Purpose

Created a structured approach to track influencer activity, lead generation, costs, and performance across multiple creators.

## Core Tracking Fields

| Field | Purpose |
|---|---|
| Influencer Name | Identify creator |
| Influencer Tier | Categorise creator |
| Platform | Identify acquisition platform |
| Audience | Understand target audience |
| Campaign | Link creator to campaign |
| Content Type | Track format |
| Date Published | Track activity |
| Tracking Link | Attribute traffic |
| Leads | Measure acquisition |
| Qualified Leads | Measure lead quality |
| Cost | Track investment |
| CPL | Measure efficiency |
| Conversion | Measure downstream performance |

## Influencer Performance Funnel

```text
Influencer
    ↓
Content Published
    ↓
Audience Engagement
    ↓
Link / CTA
    ↓
Lead
    ↓

    ↓
